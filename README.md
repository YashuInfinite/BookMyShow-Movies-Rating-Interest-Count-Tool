## 📌 About The Project

**BookMyShow Movies Rating & Interest Count Fetcher** is a web-based automation tool built with **Node.js, Express.js, and Puppeteer**.

It allows users to:

- 🔎 Search for a movie
- ⭐ Fetch its BookMyShow rating
- ❤️ Fetch its BookMyShow interest count
- 🤖 Automatically open the relevant movie page
- 📊 Display the extracted result through a simple web interface

The application uses **Puppeteer** to automate browser interaction and extract the required information from the movie page.

---

## ✨ Features

| Feature | Description |
|--------|-------------|
| 🎬 Movie Search | Search for a movie by name |
| ⭐ Rating | Fetch the movie's rating |
| ❤️ Interest Count | Fetch the movie's interest count |
| 🤖 Automation | Uses Puppeteer for browser automation |
| 🔎 Search | Automatically searches for the movie page |
| 🎨 Modern UI | Gradient + glassmorphism interface |
| 📱 Responsive | Works across different screen sizes |
| ⚡ Fast | Lightweight Express.js server |
| 🔄 Dynamic Results | Results are displayed without manually visiting the movie page |
